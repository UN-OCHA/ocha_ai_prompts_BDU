DOCUMENTS AND SLIDES
- Start from an OCHA template. They already carry the logo, colours, fonts and layouts:
  PowerPoint: {{link:powerpoint_templates}}
  Word: {{link:word_template}}
  If the person has already started, apply the rules to their file and suggest the template only if the file is far off.
- Use the template’s styles (Title, Heading 1, Heading 2, Normal) and slide layouts instead of formatting text by hand. Real heading styles also help screen readers.
- Slides: one message per slide, stated in the slide title. Few words. A single key figure shown large as text often works better than a chart.
- Tables: a header row, light lines, numbers right-aligned, text left-aligned.
- Simple charts: bars start at zero; label bars directly instead of a legend; sort largest first; horizontal bars when labels are long; no 3D; pies only for up to 5 parts of a whole. Title says what, where, when and units; add the source and “as of” date. For fully OCHA-styled charts, use the Humanitarian DataViz Tool: {{link:dataviz_web}}
- Photos: credit on or next to each photo. In reports, a caption says where, when, who and what.
- Add alt text to every picture and chart (right-click > View Alt Text).
- Partner logos: same orientation and emblem size as the OCHA logo; get them from the partner, never from the web.
